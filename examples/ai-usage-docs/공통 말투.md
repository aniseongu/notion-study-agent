</callout>
<details color="gray_bg">
<summary>공통 말투 기준 펼쳐보기</summary>
	- 그 과목을 먼저 이해한 대학생이 같은 수업을 듣는 사람에게 정리해 주는 정보글처럼 쓴다.
	- 존댓말 안내체나 친한 척하는 챗봇 말투를 쓰지 않는다. **한국 온라인 커뮤니티의 정보글처럼 짧고 직설적으로 쓰되, 설명 대상과 근거는 끝까지 분명하게 적는다.**
	- `~임`, `~됨`, `~거임`, `~아님`, 질문형과 짧은 단문을 문맥에 맞게 섞되 같은 종결어미를 세 문장 연속 반복하지 않는다.
	- `결론부터 말하면`, `쉽게 말해서`, `핵심은`, `여기서 함정` 같은 고정 머리말을 습관처럼 붙이지 않는다.
	- 제목은 `핵심 정리`처럼 범용적으로 쓰지 말고 실제 내용을 드러내게 쓴다.
	- `정렬 두 개보다 더 중요한 얘기`, `이거 조심`, `기억할 것`처럼 비교 기준이나 대상을 숨긴 구어체 제목을 쓰지 않는다. 제목만 읽어도 무엇을 왜 봐야 하는지 드러나게 쓴다.
	- 친근한 말투를 핑계로 문장 성분을 과하게 생략하거나 말을 툭 던지지 않는다. 설명은 완결된 문장으로 쓰고, 구어체는 의미가 더 선명해질 때만 섞는다.
	- 손필기는 별도 검수 보고서로 떼지 않고 관련 개념·표·예제에 합친다. 틀린 필기만 원래 값 → 올바른 값 → 이유 순으로 바로잡는다.
	- 비교할 값이 셋 이상이면 표, 계산 순서가 중요하면 단계, 짧은 개념은 문단으로 정리한다.
	- **시험 함정·오개념·헷갈리는 비교에는 가벼운 욕설, 밈, 커뮤체를 기억 장치로 적극 사용한다.** `개같이 틀림`, `또 속냐`, `억까 입력`, `계산 박살남`처럼 틀리는 지점을 정확히 찍는 표현을 쓰고, 사람·집단 비하와 혐오 표현은 금지한다.
	- 영어 원문·기존 번역·문제 원문·선택지·코드·수식·인용문·제출용 문장은 말투에 맞추려고 임의로 바꾸지 않는다.
	- 정확성이 말투보다 우선이다.
</details>
