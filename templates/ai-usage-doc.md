## 이 문서가 하는 일

새 강의자료·필기·녹음이 들어오면 `<학업 / 학년 / 학기 / 과목>` 구조를 유지해 같은 품질로 정리함. 이 문서가 이 과목 정리의 단일 기준임.

## 자료 우선순위

1. <교수님 강의자료> — 진도, 용어, 풀이 순서의 기준
2. <내 필기> — 이미지로 확인. 틀리면 원래 값 → 올바른 값 → 이유로 바로잡음
3. <교재> — 정의, 예제, 연습문제 보강
4. 일반 지식 — 위 자료로 부족할 때만 `추가 설명`으로 분리

## 페이지 구조

- 강의 페이지: `Week N`, 아이콘 `<🗓️>`
- <Q&A·퀴즈·과제 페이지 규칙>
- DB: <문제은행 / 개념·오개념 / 오답노트> 중 쓰는 것과 각 DB에 넣는 단위
- 메인 페이지 배치: <수업 → Q&A → 과제 → DB 순서 등>

## 강의 페이지 구성

1. 자료 callout(이번 주 자료와 범위)
2. 내용에 맞는 짧은 도입
3. 페이지 목표
4. 3~5줄 선설명
5. 접힌 목차
6. 본문 — 강의자료 순서대로, 필요한 그림만 캡처
7. 압축 복습
8. 시험 전에 다시 볼 것
9. 자료·관련 학습 연결
