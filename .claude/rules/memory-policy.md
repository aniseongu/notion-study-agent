# 메모리 관리

상위 규칙: [AGENTS.md 7절](../../AGENTS.md).

## 무엇을 기록하는가

- `workspace-map.md`: 다시 검색하는 비용을 줄이는 안정된 ID, URL, 스키마, 관계
- `recipes.md`: 같은 요청을 다시 실행할 수 있는 완전한 계약
- `decisions.md`: 사용자가 명확하게 확정한 선호와 운영 선택
- `error-log.md`: 원인과 재발 방지가 확인된 실패
- `style-profile.md`: live AI 활용 문서에서 검증한 공통 말투와 과목별 차이의 압축본

## 무엇을 기록하지 않는가

- 전체 대화, Notion 페이지 본문, 도구 출력 원문
- 일회성 진행 상황과 매 호출 로그
- 추측한 페이지 ID, 확인하지 않은 스키마, 임시 검색 결과
- 자격 증명과 개인 정보

## 갱신 규칙

- workspace 정보에는 `verified_at`과 확인 방법을 적는다.
- schema가 달라지면 이전 값을 조용히 덮지 말고 변경 사실과 영향을 기록한다.
- plan이 두 번 이상 성공적으로 재사용될 때 recipe로 승격한다. 사용자가 “앞으로 항상”이라고
  명시하면 한 번의 확정으로도 승격할 수 있다.
- error log의 같은 원인이 두 번 나오면 관련 규칙·recipe·검사 도구를 고치고 로그를 압축한다.
- 6개월 이상 검증되지 않은 workspace map 항목은 쓰기 전에 반드시 재확인한다.
