# 과목별 Notion 「AI 활용 문서」 — 읽고 시작하기 (2026-10-07 사용자 지시)

상위 규칙: [AGENTS.md 1절 12번](../../AGENTS.md).

과목 Notion 작업은 Notion에 있는 그 과목의 `AI 활용 문서` 페이지(로컬 파일이 아님)를 live fetch해 **처음부터 끝까지 읽은 뒤에만** 시작한다. 이 문서가
과목별 자료 범위, 페이지 구조, 캡처·문제은행 규칙, 말투, 게시 후 갱신할 절을 정하는 사용자 규칙 원본이다.
스킬·recipe·로컬 메모리는 이 문서를 빠르게 찾기 위한 사본일 뿐이다.

## 적용 범위

- 과목 트리(`학업 / 2학년 / 2학기 / <과목>`) 아래의 **모든** Notion 작업: Week·Q&A 페이지 생성·수정, 문제은행·
  개념·연결표 DB 행, 과목 메인 페이지 정리, 아이콘·제목 변경, 짧은 단건 수정까지 포함한다.
- 읽기 전용 감사(`audit-notion`), Codex 초안·검토 패킷 작성, 서브에이전트 지시처럼 Notion에 직접 쓰지 않는
  준비 단계도 포함한다. 패킷이 문서와 어긋나면 결과물도 어긋나기 때문이다.
- 과목 문서 ID는 [workspace-map.md](../memory/workspace-map.md)의 「학업 작성 기준 페이지」 표에 있다. 표에 없는
  과목이면 과목 부모 페이지의 자식에서 찾고, 그래도 없거나 둘 이상이면 사용자에게 확인한다(추측 금지).

## 절차

1. **live fetch로 전문을 읽는다.** 검색 결과 snippet, [style-profile.md](../memory/style-profile.md), 스킬 안의 요약·
   체크리스트, 지난 세션에서 읽었다는 기억은 대신할 수 없다. 공통 말투 synced block도 읽는다. fetch 결과가
   파일로 저장될 만큼 크면 그 파일을 끝까지 읽는다.
2. **기록한다.** 과목명, fetch 시각(`Asia/Seoul`), fetch 결과에 보이는 문서 최종 수정 시각을 plan·review packet·
   그날 일지에 적는다. 단건 작업은 완료 보고 한 줄로 충분하다.
3. **작업 계약에 반영한다.** 이번 작업에 걸리는 절(자료 범위·우선순위, 페이지 구조, 캡처, 문제은행, 말투, 게시 후
   갱신 지시 등)을 짚어 plan 또는 대화의 작업 계약에 옮긴다. 해당 절이 없으면 "해당 절 없음"이라고 적는다.
4. **다시 읽어야 할 때:** 다른 과목으로 넘어갈 때(과목마다 따로), 새 세션을 시작할 때, 사용자가 문서를 고쳤다고 할
   때, 긴 작업에서 게시 직전에 최종 수정 시각이 바뀌었을 때. 바뀌었으면 바뀐 절을 읽고 패킷·체크리스트를 먼저 고친다.
5. **위임할 때:** Codex 초안·검토자와 서브에이전트는 Notion을 끄고 돌리므로, 패킷에 해당 절의 요약과 문서 최종
   수정 시각을 적는다. 요약은 문서 문구를 바꾸지 않고 옮긴다.

## 충돌 처리

- 형식·구조·말투·게시 규칙과 강의자료 사이의 출처 순서·경계에서는 **현재 사용자 지시 > live AI 활용 문서 >
  스킬·recipe·로컬 메모리·이 저장소 기본값**이다.
- 내용 사실(정의·수치·문제 원문)은 사용자가 지정한 원본 자료가 정한다(AGENTS.md 2절 2번). 문서는 그 자료를 어떤
  순서·경계로 쓸지를 정할 뿐, 원본에 없는 사실을 만들지 않는다. 자세한 순서는 [learning-materials.md](learning-materials.md).
- 문서와 로컬 사본(스킬, `references/` 체크리스트, style-profile, recipe)이 다르면 문서를 따르고 로컬 사본을 고친다.
- 사용자 지시가 문서와 다르면 지시를 따르되, 문서도 고칠지 사용자에게 묻는다. 묻지 않고 문서를 고치지 않는다.

## 문서 자체를 고칠 때

- AI 활용 문서는 사용자 규칙 원본이다. 문서가 작업 후 갱신하라고 지시한 절(예: 어떤 과목의 `이어받기 상태`,
  `원자료 연결표`)만 작업 범위로 고친다. 규칙 문구는 사용자가 요청할 때만 고친다.
- 고치기 전 해당 절을 다시 fetch하고, 고친 뒤 재조회해 그 절만 바뀌었는지 확인한다.

## 실패

- fetch가 실패하거나 권한이 없거나 문서를 특정할 수 없으면 그 과목 Notion에는 쓰지 않는다. 로컬 준비까지만 하고
  원인(연결 끊김·권한·대상 불명확)을 구분해 보고한다.
